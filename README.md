# Café Control

Prototipo web para gestionar la operación de un pequeño negocio de café.

## Módulos

- Panel principal
- Proveedores
- Compras de café
- Inventario de materia prima
- Producción y empaque
- Productos terminados
- Clientes
- Punto de venta
- Reportes e indicadores

## Ejecutar localmente

No requiere instalación. Descarga el repositorio y abre `index.html` en un navegador.

> Esta versión es un prototipo visual con datos de ejemplo. Para uso real, el siguiente paso es conectar una API y una base de datos.
